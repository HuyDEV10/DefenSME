# Definition of Done — DefenSME MVP

The project reaches 100% only when every applicable item is verified:

- [ ] Authentication and RBAC work.
- [ ] Asset management is complete.
- [ ] Manual and JSON/CSV alert intake work.
- [ ] Alert lifecycle is enforced.
- [ ] AI returns schema-valid structured output.
- [ ] Users can accept, edit, or reject AI output.
- [ ] AI failure does not block manual handling.
- [ ] An incident can reach `CLOSED` with complete history.
- [ ] Important state changes and AI decisions are audited.
- [ ] Dashboard and reports use correct reviewed organization data.
- [ ] Organization isolation is tested.
- [ ] CI test, lint, and build checks pass.
- [ ] Docker Compose starts from a clean environment.
- [ ] Demo accounts and representative data exist.
- [ ] PRD, architecture, API, test report, user guide, and AI evidence are complete.
- [ ] The primary end-to-end demo passes.
- [ ] No blocker or critical defect remains open.
- [ ] Tag `v1.0.0` is published by 2026-11-30.

For each checkbox, add evidence to `PROGRESS.md` or the final test report. “Implemented” without verification is not Done.
